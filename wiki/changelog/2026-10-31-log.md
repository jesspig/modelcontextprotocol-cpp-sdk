- 2026-10-31-03 — 请求会话上下文与 stateful HTTP 多会话路由（T-05）

  - **范围**：`include/mcp/JsonRpc.hpp`、`include/mcp/server/RequestContext.hpp`、`include/mcp/protocol/McpSessionHandler.hpp`、`include/mcp/transport/StreamableHttpServerTransport.hpp`、`src/http/StreamableHttpServerTransport.cpp`、`src/protocol/McpSessionHandler.cpp`、`src/server/McpServer.cpp`、`tests/unit/McpServerTests.cpp`、`tests/unit/SessionStoreTests.cpp`；wiki 改 `classes/mcp-server.md`、`modules/transport.md`、`transports/streamable-http.md`、`tests.md`。
  - **RequestContext**：新增 `std::string_view SessionId() const`，内部持 `std::string` 拷贝；`McpServer::HandleCallTool` 与 MRTR resume 两处从 `req.session_id` 传入。stdio 与 stateless HTTP 为空串，stateful HTTP 为请求头 `mcp-session-id` 对应会话；不把实例级 `McpServer::SessionId()`（任务 owner）冒充请求会话 id。
  - **消息传递**：`JsonRpcRequest`/`JsonRpcNotification`/`JsonRpcResponse`/`JsonRpcErrorResponse` 增加非序列化 `session_id` 字段；`StreamableHttpServerTransport` 在请求送入 channel 前标注会话，`McpSessionHandler` 在成功响应、处理器异常、`SendErrorResponse` 等路径回填同一会话 id，传输按 `(session_id, request_id)` 复合键匹配 pending，跨会话同 JSON-RPC id 不串线。
  - **stateful 多会话**：`initialize` 无会话头时生成随机会话 id 并注册本地 `sessions_`/可选 `SessionStore`，响应回 `mcp-session-id`；后续请求按头解析，store `Load` 刷新滑动窗口，未知或闲置超 30 分钟 → 404 `-32009`；无头非 `initialize` 保留空会话 id 旧路径，无头 DELETE 保留兼容性 200 空操作（严格规范应为 400，见偏离项）。
  - **隔离**：pending/响应按复合键隔离；GET SSE 的 `sse_client_tag` 编入 `__session`/`__stream:"get"`，listen 持开流编入 `__session`/`__stream:"listen"` 并保留 filter 判定，带会话 id 的通知只投递同会话监听流；EventStore 按会话分区 Append/回放/Clear；DELETE 仅关闭目标会话并清其 pending/EventStore/注册，不影响其他会话；`Close()` 清理全部本地会话。
  - **验证**：`cmake --preset debug` + `cmake --build --preset debug` 通过；T-05 分支全量 `ctest --preset debug` **957/957 通过**（real 208.92s）。新增 8 用例：`McpServerTest.ToolContextExposesRequestSessionId`、`McpServerTest.ToolContextSessionIdEmptyWithoutRequestSession`、`McpServerTest.ProtocolStateIsolatedPerSession`、`SessionStoreTest.InitializeCreatesDistinctStableSessions`、`SessionStoreTest.ConcurrentSessionsIsolatePendingResponses`、`SessionStoreTest.StatelessRequestsCarryEmptySessionId`、`SessionStoreTest.ExpiredSessionIsRejectedWith404`、`SessionStoreTest.SseAndEventStoreIsolatedPerSession`。集成后基线见本文件后续 T-06 条目。
  - **补做（按会话协议状态与任务归属）**：`McpSessionHandler` 增加按会话的协商版本/codec/client capabilities 表，订阅表改为先按会话分桶；`McpServer` 增加按会话的 client capabilities/client info/initialized 标记，任务 id 与 owner 按请求会话生成，任务状态通知只投递对应会话。`ProtocolStateIsolatedPerSession` 覆盖 legacy 与 modern（discover）两会话并存、会话级版本与能力互不串扰。
  - **偏离/限制**：未引入每会话独立 `McpServer` 实例（注册 API 绑定单一 server/transport，克隆注册表超出本任务范围）；工具/资源注册表仍为实例级共享，按会话状态表隔离协商版本、codec、client capabilities/info、initialized、订阅与任务 owner。无头 DELETE 为兼容既有测试保留 200 空操作，未按规范返回 400。MRTR resume 构造点的会话 id 透传已实现，但未单列 resume 专项用例（由共享 `RequestContext` 构造与编译覆盖）。
