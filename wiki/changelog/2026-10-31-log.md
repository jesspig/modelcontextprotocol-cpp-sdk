# 2026-10-31 更新记录

- 2026-10-31-03 请求句柄与取消语义（T-04）：新增 `RequestHandle`（请求 ID + `future<RequestOutcome>` + `Cancel`）、`CancelToken`、`IRequestCanceller` 与 `RequestOptions::{timeout,cancel_on_timeout,cancel_token}`；`McpClient::SendRequest(method, params, RequestOptions)` 返回类型化句柄，新增 `SendRequestRaw` 保留 raw JSON 错误语义，旧 `SendRequest(..., meta, timeout)` 作为兼容 raw 重载；`McpSessionHandler::CancelRequest` 与 `CheckTimeouts` 统一从 pending 取出条目、清理 progressToken/绝对截止并投递 `RequestCancelled`，legacy/stdio 发 `notifications/cancelled`，modern Streamable HTTP 经 `IRequestCanceller` 关闭请求 SSE 流且不发通知，避免双重结算；新增 `examples/RequestCancellation` 演示自定义方法超时与显式取消。验证：debug 构建通过，`mcp-wire-codec-tests` 的 4 个新增取消/超时用例与 `mcp-client-tests` 的 5 个句柄/错误模型/取消用例通过，示例输出超时 -32001 与取消 -32800。
