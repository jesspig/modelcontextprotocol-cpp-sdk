# 2026-09-12 更新日志

## 2026-09-12-06 — 服务端 Bearer 鉴权（RFC 6750/9728）

- `StreamableHttpServerOptions::bearer_auth`（`optional<BearerAuthConfig>`，[StreamableHttpServerTransport.hpp](../../include/mcp/transport/StreamableHttpServerTransport.hpp)）：`verify` 回调必填（`AuthResult{ok, scopes}`，缺失构造抛 `InvalidRequest`）、`resource_metadata_url`、`scopes_supported`、`required_scopes`（全覆盖语义，空禁用）、`authorization_servers`、`serve_metadata_endpoint`（默认 true）
- `HandlePost`/`HandleGet` 入口 `AuthorizeRequest`：无头/非 Bearer → 401 + `WWW-Authenticate: Bearer resource_metadata="..."`；无效 token → 401 + `error="invalid_token"`；scope 不足 → 403 + `error="insufficient_scope", scope="..."`；错误体 JSON-RPC `-32000`；auth gate 位于一切会话处理之前
- `serve_metadata_endpoint` 注册匿名 `GET /.well-known/oauth-protected-resource`：RFC 9728 字段 `resource`（从 metadata URL 反推）/`authorization_servers`/`scopes_supported`/`bearer_methods_supported: ["header"]`
- 未配置时零回归；客户端侧经 `auth_challenge_handler` 闭环集成用例（成功 + scope 不足）

## 2026-09-12-06 — 存储参考实现：FileEventStore 与 SessionStore

- `EventStore` 接口虚化（虚析构 + 三方法 virtual），内存实现保留为基类默认
- 新增 `FileEventStore`（[FileEventStore.hpp](../../include/mcp/storage/FileEventStore.hpp) + [FileEventStore.cpp](../../src/http/FileEventStore.cpp)）：每会话 JSONL 文件 + `.lock` 锁文件；跨进程文件锁（Win32 `LockFileEx` / POSIX `flock`，RAII 独立句柄）；会话 id 双射净化（`~hh` 转义）；torn tail 跳过 + 追加前补换行；超 1024 经 `WriteAtomic` 全量重写裁剪；`Clear` 删文件。`FileEventStore.cpp` 须置于 unity TU 末尾（winsock 包含顺序，CMakeLists 注释固化）
- 新增 `SessionStore` 抽象（[SessionStore.hpp](../../include/mcp/http/SessionStore.hpp)）：`SessionRecord{protocol_version, created_at_ms}` + `Save/Load/Remove`，`InMemorySessionStore` 默认实现；`StreamableHttpServerOptions::session_store` 注入后 stateful 模式会话可跨实例接管——构造期 `Save`、请求入口 `EnsureSession`（store 命中则 `AdoptSession` 切换，后续 EventStore/DELETE 按 `ActiveSessionId`）、未知 id → 404 + `-32009`；`initialize` 响应回 `mcp-session-id` 头；DELETE 时 `Remove`
