# 2026-08-28 更新日志

## 2026-08-28-15 — 可观测性增强：日志钩子 + bind_host 可配置 + 诊断日志

- 新增全局日志钩子（`include/mcp/Log.hpp`）：`SetLogHandler` / `GetLogHandler` / `SetLogLevel`；`LogRecord` 结构化记录（level/tag/message/file/line/context）；设钩子后替代 stderr，传 `nullptr` 恢复默认。
- 日志级别可由 `mcp::SetLogLevel` 运行时覆盖 `MCP_LOG_LEVEL` 环境变量（原实现为静态缓存、不可运行时变更）。
- `HttpServerOptions::bind_host` 与 `StreamableHttpServerTransport` 的 `StreamableHttpServerOptions::host`：监听地址可配置（仅 IPv4 字面量，空 = `INADDR_ANY`），向后兼容。
- `HttpServerImpl`：`bind` 前打印 `binding <addr>:<port>`（Info）；bind 失败消息含地址；非法 `bind_host` 抛 `std::runtime_error`；403 日志安全补被拒 `Host`（缺省 `<missing>`，无 `Host` 不崩）。
- 测试：`tests/unit/LogTests.cpp`（钩子捕获 / 级别过滤 / 钩子异常不崩 / 恢复默认不崩）、`tests/unit/HttpServerTests.cpp` 增 bind_host 用例与无 `Host` 403 不崩用例。

## 2026-08-28-16 — bind_host 支持 IPv6 监听地址

- `HttpServerImpl::Start` 按 `bind_host` 字面量自动选族：先 `inet_pton(AF_INET6)` 再 `inet_pton(AF_INET)`，支持 IPv4/IPv6 字面量（如 `127.0.0.1` / `::1` / `::`，可用 `[]` 包围）；均失败抛 `std::runtime_error`。
- 空 `bind_host` 仍仅 `INADDR_ANY`（IPv4，向后兼容），`AcceptLoop`/`Stop`/`TcpSocket` 无需改动（均族无关）。
- 更新 `HttpServerOptions::bind_host` 与 `StreamableHttpServerOptions::host` 注释说明 IPv6 支持。
- 测试：`tests/unit/HttpServerTests.cpp` 新增 `BindHostIpv6LoopbackAccepts`（含 IPv6 不可用跳过）与 `BindHostInvalidIpv6Throws`。
