# 2026-10-18 变更日志

## 2026-10-18-13 引入 `MCP_WITH_OPENSSL` 三态开关并以 `mcp-openssl` 收口 OpenSSL 编译定义与链接

- **范围**：CMake 侧新增三态开关 `MCP_WITH_OPENSSL`（取值 `AUTO`/`ON`/`OFF`，默认 `AUTO`）与单一 INTERFACE 目标 `mcp-openssl`；`src/ext/DPoP.cpp` 去掉 `__has_include` 头文件嗅探，改为严格跟随 `MCP_HAVE_OPENSSL`。文档与知识库同步：`docs/zh/guide/installation.md`、`docs/en/guide/installation.md`（依赖表补开关 + 三态语义）、`docs/zh/client/oauth.md`、`docs/en/client/oauth.md`（OpenSSL 要求段改写）、`README.md`、`README_zh.md`（可选依赖行补开关）、[build.md](../build.md)（预设与开关表、依赖表补开关）、[dpop.md](../concepts/dpop.md)（「OpenSSL 可选依赖」条目改写 + frontmatter）、[AGENTS.md](../../AGENTS.md)（「构建与测试」段与关键陷阱第 3 条）、本文件与 [log.md](../log.md)。
- **根因**：`src/ext/DPoP.cpp:8-16` 在 `MCP_HAVE_OPENSSL` 未定义时改用 `__has_include(<openssl/ec.h> … <openssl/rand.h>)` 嗅探头文件来开启 OpenSSL 调用路径；而编译该文件的 `mcp-ext` 目标**从不被定义 `MCP_HAVE_OPENSSL`**——`CMakeLists.txt:171-176` 只把 `MCP_HAVE_OPENSSL` 定义与 `OpenSSL::Crypto`/`OpenSSL::SSL` 链接加在 `mcp-client`/`mcp-transport` 上。于是「开发头文件可见但未链接 OpenSSL」的机器（如 Ubuntu 上显式 `-DCMAKE_DISABLE_FIND_PACKAGE_OpenSSL=ON`、或未把 OpenSSL 库加入链接）会编译通过、链接期报未定义符号。
- **修复**：新增 `MCP_WITH_OPENSSL` 显式控制启用与否（`AUTO` 按 `find_package(OpenSSL)` 结果决定；`ON` 未找到即 configure 失败；`OFF` 强制禁用，即使本机装有 OpenSSL 也不启用），并以单一 INTERFACE 目标 `mcp-openssl` 把 `MCP_HAVE_OPENSSL` 定义与 OpenSSL 链接一次性施加到 `mcp-transport`/`mcp-client`/`mcp-ext` 三个目标，消除 `mcp-ext` 的定义缺口；`DPoP.cpp` 删除 `__has_include` 嗅探，编译定义与链接结果单一来源，头可见与链接状态不再可能背离。
- **文档同步要点**：删除「由 `__has_include` 头文件嗅探推断 OpenSSL 可用」的旧表述，统一改为「启用与否由 `MCP_WITH_OPENSSL` 与 `find_package(OpenSSL)` 结果决定」；`docs/{zh,en}/guide/installation.md` 保留「configure 阶段无需联网」表述并补三态语义；`README.md`/`README_zh.md` 可选依赖行补开关名。`docs/zh/guide/installation.md` 与 `docs/en/guide/installation.md` 关于「configure 无需联网」的既有差异（英文版原先缺该句）本次一并对齐。
- **验证**（主任务实测，Windows / clang-cl；本机未安装 OpenSSL）：`-DMCP_WITH_OPENSSL=OFF` 配置打印 `[mcp] OpenSSL disabled (MCP_WITH_OPENSSL=OFF)`；全量构建 75/75 目标成功（含全部测试可执行文件链接）；`ctest --preset debug` 837/837 通过；`compile_commands.json` 中 `MCP_HAVE_OPENSSL` 出现 0 次。`-DMCP_WITH_OPENSSL=AUTO` 未找到时打印 `[mcp] OpenSSL not found — TLS disabled, PKCE uses built-in SHA-256`。`-DMCP_WITH_OPENSSL=ON` 在缺 OpenSSL 时 configure 立即失败（`Could NOT find OpenSSL`）。对 `src/` 递归扫描 `__has_include(<openssl` 命中 0。
- **CI**：三平台矩阵新增 3 条 `openssl: off` 分支（共 11 条），Configure 追加 `-DMCP_WITH_OPENSSL=OFF`，OFF leg 与 auto leg 同样运行完整 `ctest`；sccache 缓存键纳入 `matrix.openssl` 以隔离两者缓存。`ON` 命中 OpenSSL 的成功路径与 `mcp-ext` 在启用态获得 `MCP_HAVE_OPENSSL` 依赖三平台 CI 覆盖（本机无 OpenSSL，无法本地验证）。
- **遗留**：`master` 分支尚无此开关与 `mcp-openssl` 目标，下次自 `develop` 拉 `release/*` 时随带。
