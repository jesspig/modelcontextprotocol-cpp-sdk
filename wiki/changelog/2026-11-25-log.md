- 2026-11-25-01 — HTTP 边界解析、SSE 增量分帧与 202/bind 收紧（ST-03，任务 T-12，分支 `feature/sdk-http-runtime-hardening`，基线 HEAD `99804b1`）。新增共享 [HttpFraming.hpp](../../include/mcp/detail/HttpFraming.hpp)：`ParseCheckedDecimal`/`ParseCheckedHex` 先做乘法溢出检查再比上限，请求与响应的 `Content-Length` 拒绝空值、非数字、重复头、超出 `size_t` 与超限；`Transfer-Encoding` 与 `Content-Length` 共存确定拒绝，chunk size 溢出和累计 body 上限受同一检查约束，WinHTTP 路径以有界读取和同一 202 语义收口。[SseEventParser.hpp](../../include/mcp/detail/SseEventParser.hpp) 升级为 `SseIncrementalParser`：任意分块、CRLF/LF/单独 CR/混合换行等价，跨块末尾 `\r` 保留到下一字节，空行派发，注释/多行 `data`/`id`/`event`/`retry` 共用规则，事件上限继续生效；SSE client、Streamable HTTP POST 响应、GET listen 与 resume 全部复用并删除各自的 `\n\n` 分隔逻辑。202 限定通知确认：空 body 直接完成，不进 JSON/SSE 解析；请求收到 202 立即投递 `ProtocolViolation (-32005)` 给 pending 并关闭/排空连接，不自动重放。`HttpServerOptions::bind_host` 空值默认改为 IPv4 loopback（`kDefaultBindHost = "127.0.0.1"`），显式 `0.0.0.0` / `::` 仍可绑定全网，默认卡片端点保持 `localhost`。新增溢出、重复/畸形头、TE-CL 冲突、chunk 溢出、三种换行混合、跨块 CR、超长事件、202 通知/请求与默认/通配 bind 测试；验证 `cmake --preset debug`、`cmake --build --preset debug`、定向 ctest 与全量 ctest（证据见 `.handoff/evidence/T-12/tests.txt`）。源码兼容、双 era 与旧 API 不变；行为收紧（默认 bind、202 请求、framing 严格化）的旧行为/新行为/如何改见 `docs/{zh,en}/reference/transports.md`。未改全局迁移页（T-24 负责）、未提交。
